# Rabin Joshi Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP.
2. Open the `rabin-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Edit `index.html`, `style.css`, and `script.js` as you learn.

## Personalize before publishing
- Replace the placeholder contact email in `index.html`.
- Add your real public email to `publicEmail` in `script.js`.
- Replace placeholder social links with your real profiles.
- Confirm education, experience, skills, and project statuses.
- Add your own photo if you want one; the hero currently uses a CSS initials illustration.

## Important
The contact form opens the visitor's email app after you set `publicEmail`. It does not send messages directly or store them on a server.
